# tactics-brainstorm

Systems-level tactics and combined-arms brainstorms, historical counterfactuals, and transferable design theory.

## Core question

What changes when we treat combined arms not only as capability complementarity, but also as **authority choreography, temporal persistence, and recomposability**?

Working sequence:

```text
GUIDE -> RELEASE -> DISTRIBUTE -> PERSIST -> RECOMPOSE
```

Working laws:

- Local autonomy creates width.
- Central direction creates precision.
- Exceptional recall creates coherence.
- Temporal sovereignty prevents the present from erasing the past.
- Effective strength includes current capability, stored options, and the ability to recombine them.
- A satisfying counterattack exploits a battlefield state created before the counterattack began.
- Expert action should often sit on top of a robust safe floor rather than require abandoning it.

## Method

This repo is for historical analysis, game-derived systems theory, and high-level tactical thought experiments. Keep source-backed history separate from speculative counterfactuals. When a mechanic inspires a military analogy, preserve the analogy as a model rather than pretending the game is historical evidence.
